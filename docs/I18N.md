# Web 界面语言 / Web interface language

NovelForge Web offers Simplified Chinese (`zh-CN`, the default) and English (`en`). Use the selector in the header or Settings. Both selectors control the same browser preference, `novelforge-locale`.

## 安全边界 / Safety boundary

切换语言只更新展示状态、HTML 语言和浏览器偏好，不更新项目、小说创作语言、正文、选中文件、未保存表单、任务或模型配置；不会执行 API 写入或模型调用。页面不因语言变化重新挂载。正在运行的任务及原有轮询继续按原计划运行，不因语言切换重复启动。

Switching interface language changes display state, the HTML language and a browser preference only. It does not change the manuscript language, drafts, selected files, unsaved form inputs, projects, jobs or model configuration. It neither remounts pages nor issues API writes or model calls. Existing polling and running jobs continue independently.

The novel wizard's **创作语言 / Manuscript language** is project data and remains separate, including its existing Traditional Chinese option. User text, imported files, source Markdown skills, model IDs, provider aliases, original diagnostic payloads and protocol identifiers are not translated or rewritten. Technical details retain their original data under localized headings.

## 维护 / Maintenance

All ordinary interface phrases are in paired `web/src/lib/i18n/zh-CN.ts` and `en.ts` dictionaries. Stable message keys and parameter parity are checked. Dynamic notices retain locale-neutral keys/arguments and are translated at render time. Machine enums and safe API error codes use `system.ts`; never translate database values, action names, URL parameters or option values. Implicit option values must be made explicit before translating labels.

Language preference failures degrade to in-memory switching; invalid saved locales default to Chinese. No project database migration is involved. The Svelte store module has no API/router/task dependency. Do not use a keyed locale block, document reload, DOM text replacement, external translation service or model to translate the interface.

## Verification boundary

The focused bilingual tests cover dictionary parity, all 14 routes, accessible labels, error/notice updates, state and selected-file preservation, explicit option values, storage failure and zero additional API calls while switching. Production checking uses the embedded Go binary and a real browser without paid providers. This is not Phase 13B full regression, long-book scale, paid-model billing or all-platform runtime certification. Exact completed checks and run IDs are recorded in the delivery PR and candidate notes.
