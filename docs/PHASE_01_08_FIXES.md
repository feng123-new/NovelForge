## 验证范围

只编译 NovelForge 入口，并运行少量命名检查：字符检索、编译选中字段与必需项溢出、Writer 请求哈希/重放、模型适配器、配置到假 Provider 的 HTTP 短流程。短流程涵盖生成、审核、定稿、人工修订、再次定稿及重建服务器后的读取。仅替换付费 Provider，其余使用真实配置解析、HTTP 模型适配器、项目数据库和协调器。

## 保留的边界与风险

`quality_model_available` 是配置条件，不是健康探测，单个项目可以有自己的模型配置。假 Provider 短流程不证明所有真实 Provider 兼容性或文学质量。

上下文继续采用估算 Token 与有界查询，不证明百万字级全局召回。后续章节找不到已接受的 POV 状态时停止；旧字段分类依赖原键名/元数据。Truth/Ledger 的查询上限、各种人物登场方式及长篇召回质量未做规模验收。

字符索引依赖 Go 注册的 `novelforge_search_characters`；外部 SQLite 客户端不应直接修改索引源表。它是派生检索结构，不修改原文或事实权威。首次用新代码打开项目时，沿用现有迁移备份机制执行 Migration 8；单纯合并源码不会迁移任何用户小说。
