# NovelForge v0.1.0-rc.2 — 中英双语工作台 / Bilingual workspace

## 变化 / Changes

All 14 Web routes now offer complete Simplified Chinese and English controls, navigation, validation, task states and actionable diagnostics. Switch from the header or Settings; the browser remembers the choice. Manuscript language is independent, including existing Traditional Chinese projects.

全部 14 个页面提供中英界面。切换只改变浏览器展示偏好，不刷新页面，不改作品、创作语言、未保存正文、光标、所选导入文件或预算编辑，不暂停、重启或恢复任务，也不触发模型调用。原始正文、资料、模型名称、API 数据和技术详情保持原样。

## Upgrade / 升级

Back up the workspace before replacing the executable. Keep the existing workspace and configuration directories. No project database schema or configuration migration is introduced by interface localization. Select the matching OS/architecture archive, verify the published SHA-256 checksums, then start `novelforge server --workspace <workspace>`. An existing rc.1 binary does not update itself when main changes.

升级前备份工作区，再替换可执行文件；保留已有工作区和配置。此次国际化不引入项目数据库格式迁移。首次评估使用独立测试工作区，必要时添加 `--no-autopilot` 关闭任务执行器；该参数不是全局只读模式。

## Limits / 边界

This is a prerelease, not stable/latest. The bilingual scope is Web, not a translation of CLI/TUI, prompts or manuscripts. Technical identifiers and raw diagnostic details intentionally retain their source values. Running-job invariance uses component tests; the live-browser audit runs without a paid provider. Full Phase 13B regression, long-book scale, paid-provider billing/literary quality and Windows/macOS/ARM native runtime acceptance remain unverified. Six packages are cross-built, with native Linux no-model smoke separately recorded. SHA-256 is not OS signing or notarization.
